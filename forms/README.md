# Forms

Output templates each specialist fills. The shape of every pipeline artefact is defined here before the specialist that produces it.

| `matrix-template.md` | Matrix Sync | 06 (post-close) | Active |

## The discipline

Forms are written before their specialist. The form is the output specification — without it, specialist-building becomes open-ended prompt tuning with no definition of done. If a specialist's output doesn't match its form, the form wins.
